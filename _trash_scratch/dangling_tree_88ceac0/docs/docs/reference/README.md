# Referencias visuales y auditorías incorporadas

Este directorio contiene copias verificadas de fuentes externas que antes
quedaban sólo en el Desktop. Su presencia mejora la continuidad de agentes,
pero no las convierte en runtime ni en una autoridad paralela.

- `visual/`: snapshots de los dos landings que gobiernan el ADN visual y el
  flujo, según `SPECT.md`.
- `audits/Qwen_html.html`: referencia auditada de diseño y estructura. Sus
  ideas sólo se reutilizan cuando siguen siendo compatibles con `SPECT.md`.

`SPECT.md` sigue siendo la autoridad de producto y arquitectura; los ADR,
`AGENTS.md`, `docs/DECISION_REGISTER.md` y el handoff canónico describen el
estado vigente. Estos archivos no se sirven desde `apps/web/public/`.
