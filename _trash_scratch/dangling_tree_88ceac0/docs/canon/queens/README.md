# Paquetes canónicos por Queen

Cada carpeta contiene artefactos derivados y auditables de una Queen. No es un prompt monolítico: `identity`, `voice`, `glossary`, `boundaries` y `eval` tienen funciones distintas. Un archivo puede estar `PENDIENTE` sin inventar contenido para llenar el hueco.

La esencia común vive en [`../SHARED_ESSENCE.md`](../SHARED_ESSENCE.md). Sólo una Queen con paquete completo, fallback registrado y benchmark `PASS` puede entrar en runtime.
